# DIY-MICROG-kangrio-USER

## Patchset bases on this [fork](https://github.com/kangrio/GmsCore-User)

## Patcher APP is Nedded by GmsCore

https://github.com/kangrio/MicroG-Patcher

## How to Install

1. Download And install ```gmscore.apk```

2. Open MicroG Settings Enter Self-check page And Grant All Permission.

3. Enter Google Accounts and login into Google Account as always

4. Download and install ```vending.apk``` as google play replacement (official google play didn't tested but may work).

5. That's All.
